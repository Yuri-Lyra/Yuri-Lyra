# Hi, I'm Yuri Lyra

QA analyst focused on **test design, risk-based testing and test automation**. My background is in biological sciences and health education, which taught me to work from evidence, state hypotheses clearly and write things others can reproduce.

## What I work with
- **Standards and methods:** ISO/IEC/IEEE 29119, ISTQB CTFL 4.0, risk-based testing, exploratory testing (session-based)
- **Techniques:** decision tables, boundary value analysis, equivalence partitioning, state-based testing, error guessing
- **Automation:** Playwright (TypeScript), Python for test oracles
- **Documentation:** test plans, test cases, charters, risk registers, defect reports
